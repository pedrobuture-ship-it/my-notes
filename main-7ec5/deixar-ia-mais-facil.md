# Deixar ia mais facil

Qual é o nome científico do cachorro? :: Canis lupus familiaris.
Quando o cachorro foi domesticado? :: Aprox. 10.000 a 30.000 anos atrás.
Qual é o ancestral selvagem do cachorro? :: O lobo-cinzento.
Quais são os dois sentidos mais apurados dos cachorros? :: Olfato e audição.
